# llama-android-vulkan-build

Cross-compile **llama.cpp (tag b11913)** for **Android arm64** with the **Vulkan backend**
via GitHub Actions (Android NDK r27c).

## Why

Mali-G77 (OnePlus Nord 2, MT6893) is detected by the llama.cpp Vulkan backend, but prebuilt
bionic binaries (Termux) segfault during Vulkan buffer/pipeline allocation due to an ABI/runtime
mismatch. This repo produces a single, consistent build so the driver and the backend agree.

## How

1. Actions -> `build-android-vulkan` -> *Run workflow* (or push to `main`).
2. Wait for the run to finish.
3. Download the `llama-android-arm64-vulkan` artifact (a `.tar.gz` with `llama-cli`,
   `llama-server`, `llama-bench` and `lib*.so`).
4. Deploy to the phone:
   ```bash
   adb push llama-android-arm64-vulkan.tar.gz /data/local/tmp/
   adb shell 'mkdir -p /data/local/tmp/llama-gpu && tar xzf /data/local/tmp/llama-android-arm64-vulkan.tar.gz -C /data/local/tmp/llama-gpu'
   adb shell 'cd /data/local/tmp/llama-gpu && LD_LIBRARY_PATH=. ./llama-bench -ngl 99 -m <model.gguf> -p 128 -n 32'
   ```

## Notes

- `GGML_NATIVE=OFF` + `GGML_CPU_ARM_ARCH=armv8.2-a+dotprod` (cross-compile, matches A78/A55).
- Vulkan shaders are generated by a *host*-compiled `vulkan-shaders-gen` (glslc + host gcc).
- Runtime uses the Android Vulkan loader (`/system/lib64/libvulkan.so`) and the Mali driver
  (`/vendor/lib64/hw/vulkan.mali.so`).
